# 🏴‍☠️ Luffy

> Luffy is a cross-platform application for browsing and watching anime.

It is built with [Flutter](https://flutter.dev/) and available for Android, iOS, macOS, Linux, and Windows.

## Features

- Watching anime from a variety of sources
- Tracker support for anime, utilizing the MyAnimeList API.
- Light and dark themes
